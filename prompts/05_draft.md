# Stage 05 — Draft
Inputs you may use as evidence: exp/results/registry.json, exp/results/fig_*, exp/results/summary.md, exp/analysis_contract.md, lit/*, journal/*. Nothing else is evidence.
Format = bonrs.yaml `paper_format`: latex → `paper/main.tex` + `paper/refs.bib` with the journal template class, built with `latexmk -pdf -interaction=nonstopmode main.tex`; docx → `paper/main.md` (Pandoc Markdown, `[@key]` citations) converted with `pandoc main.md --citeproc --bibliography refs.bib -o main.docx` (use the journal's reference .docx/.csl if available).
Write in this order: tables/figures (tables generated with `bonrs.py registry <slug> --table ...`, standalone captions) → Methods (past tense) → Results (facts only, by importance) → Discussion (5 parts: principal findings, comparison with prior work, implications bounded by data, limitations each tied to an inference, future work derived from limitations) → Conclusion → Related work → Introduction (CARS; gap and purpose must mirror each other; explicit contributions) → Abstract (journal format, numbers, no citations) → Title (keyword in first 65 chars) → keywords, highlights, declarations.
Integrity (knowledge/00-general/paper_integrity.md): every numeral is `\phm[file:key]{v}` or `\ph{v}`; write `paper/claims.yaml`; Results/Discussion sentences carry `\prov{id}{...}`; write `paper/provenance.json` mapping each section to {origin: ai-draft, tool: "Claude Code", model, date}. Compile after each section; keep it building.
Voice: follow journal/style_guide.md exemplar sentences and any knowledge/50-user voice skill. Short sentences, one idea each, key point first, no dead wood, no stacked hedges, hedge strength matched to design, avoid LLM-marker words (delve, underscore, showcase, intricate, pivotal, meticulous, tapestry, testament, landscape, interplay, leverage, multifaceted, nuanced, seamless, holistic, foster) and constructions ("not only… but also", "it is worth noting", "plays a crucial role", trailing "-ing" summaries, triplets). No em-dashes in prose.
Finish: run `python3 $BONRS_ROOT/bonrs.py audit <slug>` and fix until clean (`\ph` allowed now). Write `paper/wordcount.md` with words per section vs budget. If `/latex-paper-en` or `/paper-writing-studio` skills are available, use them for compile repair and venue formatting.
