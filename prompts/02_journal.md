# Stage 02 — Journal fit
1. Run `python3 $BONRS_ROOT/bonrs.py journal <slug>`. It writes journal/profile.json (ISSN, publisher, homepage, APC, DOAJ, h-index, recent open-access accepted papers with measured shape and an LLM-marker vocabulary baseline) and downloads journal/accepted/*.pdf(.txt).
2. Find and read the Guide for Authors (WebSearch + WebFetch; publisher URL patterns: Elsevier sciencedirect.com/journal/<slug>/publish/guide-for-authors, Springer link.springer.com/journal/<id>/submission-guidelines, Wiley onlinelibrary.wiley.com/page/journal/<eissn>/homepage/forauthors.html, T&F tandfonline.com/action/authorSubmission?show=instructions&journalCode=<code>, MDPI mdpi.com/journal/<slug>/instructions, Frontiers, PLOS). If blocked (403), try another URL or a cached copy; if still blocked, write `journal/REQUEST_GUIDELINES.md` asking the user to paste it and continue from the accepted papers. Save text + URL to journal/author_guidelines.md.
3. Decide `article_type` from the article types this journal publishes and the chosen hypothesis (research article, short communication, review, systematic review/bibliometric, case report, data paper, …); write it into bonrs.yaml `article_type` (it is `auto` until then) and follow that type's structure and word limits. Decide `paper_format` (latex if the journal provides/accepts a LaTeX template, else docx) unless bonrs.yaml already forces one; write it to bonrs.yaml. Note the template (elsarticle, sn-jnl, IEEEtran, acmart, MDPI, Word template URL).
4. Reporting guideline: classify study design and map to EQUATOR (CONSORT, STROBE, PRISMA, STARD, TRIPOD, CARE, ARRIVE, COREQ...) when biomedical or required by the guide.
5. Read 5–8 accepted papers' .txt. Extract: intro moves, how contributions are stated, Methods/Results/Discussion structure, figure/table conventions, limitation phrasing, section lengths, tone, recurring vocabulary. Copy 10 exemplar sentences showing the register.
6. Write `journal/style_guide.md` (checkable spec: section skeleton with word budgets, abstract template and limit, title pattern, keywords count, citation style, figure/table rules, mandatory statements, forbidden things, exemplar sentences) and `journal/compliance_checklist.md` (every rule → how it will be verified).
7. Save durable journal rules as a skill: `python3 $BONRS_ROOT/bonrs.py learn "<rules>" --level journal --journal "<journal name>"` (only rules, ≤400 words).
8. If the journal clearly does not fit, say so in decisions.md, switch to the first backup and redo this stage.
