# Bibliometric / review papers (if the paper is a bibliometric or systematic review)

Pick one primary tool for data processing (Biblioshiny) and one for visualisation (VOSviewer); one cleaned dataset (Scopus/WoS) exported to both; no duplicated outputs — each tool owns one analysis type (descriptive/trend vs network/cluster). Figures/maps go in Findings with short descriptions; interpretation, trends and gaps go in Discussion. Organise by analysis type, not by tool; state figure source. One representative cluster map, light comparison only. Follow PRISMA for systematic reviews.
