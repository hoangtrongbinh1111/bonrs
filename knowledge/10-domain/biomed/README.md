# Biomedical / life-science domain rules
- Map study design to an EQUATOR guideline: RCT→CONSORT 2025, observational→STROBE, systematic review→PRISMA 2020, diagnostic→STARD, prediction model→TRIPOD(+AI), case report→CARE, animal→ARRIVE 2.0, qualitative→COREQ/SRQR. Include the filled checklist as supplementary material.
- Report sample-size justification, randomisation, blinding, inclusion/exclusion, ethics approval number, consent, RRIDs, sex as a variable, software versions.
- Causal verbs only for experimental designs; observational designs use "associated with".
- Prefer Europe PMC JATS full text; use MeSH terms in queries (`bonrs lit --biomed`).
