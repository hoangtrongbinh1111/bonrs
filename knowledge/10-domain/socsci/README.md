# Economics / management / social-science domain rules
- Cross-sectional survey data cannot support causal claims; report common-method-bias checks, measurement validity (CFA, AVE, CR), sampling frame and response rate.
- Many significant SEM paths are not a theoretical contribution; name the theory extended and the mechanism.
- Bibliometric and systematic reviews: one cleaned Scopus/WoS dataset, PRISMA flow, Biblioshiny for descriptives, VOSviewer for networks (see 00-general/bibliometrics.md).
- Journals here often require Word and structured abstracts (Purpose / Design / Findings / Originality).
