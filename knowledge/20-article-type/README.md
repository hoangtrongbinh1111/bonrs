# Article types
- research: IMRaD; one main claim; results before interpretation.
- review: Abstract, Introduction, Literature review, Critical discussion, Conclusions; synthesise and evaluate, never list.
- bibliometric: PRISMA plus descriptive and network analyses (see 00-general/bibliometrics.md).
- case: CARE guideline; timeline figure; consent statement.
