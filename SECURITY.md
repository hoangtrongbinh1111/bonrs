# Bảo mật · Security

bonrs chạy mã do AI sinh ra trên server của bạn, nên lỗi bảo mật rất quan trọng với chúng tôi.

**Báo lỗ hổng:** đừng mở issue công khai. Hãy dùng [Report a vulnerability](https://github.com/hoangtrongbinh1111/bonrs/security/advisories/new) (GitHub private advisory) và mô tả:
- phiên bản hoặc commit đang dùng;
- các bước tái hiện;
- ảnh hưởng (ví dụ: người dùng A đọc được dữ liệu của B, job lấy được API key, thoát sandbox).

Chúng tôi sẽ phản hồi trong vòng 7 ngày và ghi công người báo cáo khi công bố bản vá (nếu bạn muốn).

Phạm vi: mã trong repo này. Lỗ hổng của Claude Code hãy báo cho Anthropic theo https://www.anthropic.com/responsible-disclosure-policy.
